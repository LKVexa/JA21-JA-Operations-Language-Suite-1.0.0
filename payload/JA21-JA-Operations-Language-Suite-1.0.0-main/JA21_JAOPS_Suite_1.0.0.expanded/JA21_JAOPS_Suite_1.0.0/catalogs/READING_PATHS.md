# Role-Based Reading Paths

## Operations author

Read Chapters 1–17, then use the positive and boundary script classes to construct workspaces, services, release plans, and recovery rules.

## Compiler engineer

Read Chapters 2, 3, 4, 10, and 18–21. Use negative and security records to define syntax, type, effect, capability, and policy diagnostics.

## Runtime and deployment engineer

Read Chapters 5–17 and 19–22. Focus on deterministic plans, sandboxing, probes, journaled upgrades, rollback, installer behavior, and MCRT receipts.

## Security and air-gap reviewer

Read Chapters 4, 9, 10, 14, 15, 20, and 21. Audit network declarations, secret references, artifact provenance, reproducibility, and fail-closed behavior.

## Instructor and certifier

Use the curriculum, workbook, certification guide, and all ten validation classes. Require a modeled/native evidence distinction in every submission.
