## Assessment

- Laboratories: 40%
- Negative and recovery case portfolio: 20%
- Mid-course architecture review: 15%
- Capstone suite and evidence packet: 25%

Every submission must distinguish modeled evidence, structural validation, native compiler evidence, native runtime evidence, and certification evidence.
