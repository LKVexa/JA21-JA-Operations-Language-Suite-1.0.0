# Governance Charter

## Purpose

Govern this suite as a language, evidence, education, and conformance product for JA21 operations engineering.

## Decision lenses

SOPHIA reviews semantic coherence; CHARLOTTE reviews information architecture; LANDON reviews implementation feasibility; Professor reviews proof and pedagogy; Podium reviews publication and certification readiness.

## Non-negotiable controls

- No hidden network authority.
- No secret values in source or evidence artifacts.
- No optimization that removes policy, capability, rollback, or provenance gates.
- No native-execution claim without a reproducible native report.
- No certification claim without exact artifact identity, test scope, limitations, and reviewer authority.
- Air-gapped releases must fail closed and remain independently inspectable.
