# JA Operations Publication System

## Concept: Operations Constellation

The suite presents operations as a chain of governed state transitions rather than a folder of infrastructure fragments. The visual system uses an obsidian field, teal build and integrity lines, blue deployment transitions, violet recovery/provenance signals, and restrained gold certification marks.

## Hierarchy

1. Source and language identity
2. Typed operational graph
3. Policy, capability, and recovery gates
4. R12 plan and artifact identity
5. Runtime or modeled outcome
6. MCRT receipt and certification decision

## Air-gap rules

- Use local Markdown, CSV, JSON, JSONL, Python, and SVG only.
- Do not require web fonts, remote images, HTML, CSS, JavaScript, telemetry, or network assets.
- Preserve readable monochrome output.
- Keep relative paths compact for Windows extraction.
- Never expose secret values in examples, indexes, logs, or receipts.

## Editorial voice

Use precise operational verbs: declare, resolve, lock, build, admit, schedule, probe, promote, rollback, package, verify, and certify. Separate expectation from observation and observation from certification.
