# Certification Guide

## Certification levels

1. **Package integrity** — counts, paths, hashes, catalogs, and source fidelity.
2. **Parser and semantic conformance** — syntax, names, types, effects, capabilities, and policy.
3. **Plan conformance** — deterministic lowering, topology, probes, transitions, and recovery.
4. **Runtime conformance** — observed sandbox behavior, state transitions, outputs, rollback, and replay.
5. **Release certification** — signed decision identifying exact artifacts, tools, tests, limitations, and reviewer authority.

A certificate must never imply native behavior when only corpus-modeled evidence or structural validation was performed.
